## Teknoloji envanteri

- **Backend:** NestJS + Prisma + PostgreSQL (Railway) · Zod doğrulama · JWT (30 gün TTL) · audit log servisi
- **Mobil:** Expo SDK 54 / React Native · Zustand (AsyncStorage persist) · TestFlight (arkadaş hesabı) + EAS Update kanal: production
- **Depolama:** Cloudflare R2 (anahtar doluysa), yoksa data-URL DB'de · **Queue/Job altyapısı YOK** (Redis/BullMQ kurulmadı; hiç cron/interval yok — kanıt: `grep Cron|Interval|Scheduler apps/api/src` boş)
- **Admin:** Next.js (yerel :3100) → prod API; tek `admin` hesabı, rol=admin JWT; MFA yok

## Önerilen faz sırası (plan onayına sunulur)

- **Faz 1 (randevu çekirdeği):** süre-aşımı job altyapısı (tek başına en kritik eksik — node-cron ya da basit interval servisiyle: awaiting 6s / dekont 3s düşürme) → çalışma saati+izin entegre gerçek slot üretimi (hours/closedDays zaten DB'de) → DB exclusion constraint + 20-paralel test
- **Faz 2 (finans):** dekont hash + tekillik + signed URL · kapora yüzde formülü (karar sonrası) · completed/no-show teyit penceresi
- **Faz 3 (offline):** SYNC_CONFLICT durumu + çıkışta bekleyen kayıt onayı
- **Faz 4 (salon):** busy-only görünürlük + yetki modları
- **Faz 5 (pazaryeri):** kademeli eşleştirme + doğrulanmamış uzman kapora kısıtı
- **Faz 6 (borç):** medya arka plan migrasyonu · bildirim yerelleştirme · saklama matrisi
